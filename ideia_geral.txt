Primeira Decisão Importante
Antes de avançarmos, preciso que penses nisto:
Como queres estruturar o backend?

Opção A: Python (Flask/FastAPI) - Usa mesma linguagem do modelo, mais direto
Opção B: Node.js - Se preferires JavaScript no backend também

E para o frontend:

Opção A: HTML/CSS/JavaScript puro - Mais simples, sem frameworks
Opção B: React - Mais robusto, mas mais setup
